# Galería de dibujos
Página para guardar mis dibujos: subir imagen, título y descripción.
Stack: Node.js + Express, EJS, Multer, SQLite.
Estoy aprendiendo: explícame cada cambio y avanza paso a paso.

Descragas iniciales:
-mkdir galeria-dibujos && cd galeria-dibujos
-npm init -y
-npm install express ejs multer
-mkdir views public uploads

Para ejecutar el servidor:
node --watch index.js
